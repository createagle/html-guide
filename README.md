# HTML Complete Guide · Demos

**English** | [简体中文](README.zh-CN.md)

Companion demos for *HTML Complete Guide* (5 parts, 40 chapters), deployed on GitHub Pages:

**https://createagle.github.io/html-guide/**

## Layout

```text
index.html                     # Demo index (by part and chapter), generated by tools/build_index.py
assets/
  style.css                    # Shared styles: light/dark theme, centered demo layout, prefers-reduced-motion
chapters/
  01-intro/
    README.md                  # Chapter demo list
    01-layers.html             # One demo per standalone page
    exercises/                 # Exercise starter (NN-start) and finished (NN-final) code
  02-syntax/
  ...
tools/
  build_index.py               # Rebuilds index.html from the chapter READMEs
  reading_time.py              # Estimates a chapter's reading time from its Markdown export
.github/workflows/
  pages.yml                    # Deploys to GitHub Pages on every push to main
  sync-main.yml                # Fast-forwards claude/** branches into main, then deploys
```

- Demo URL: `https://createagle.github.io/html-guide/chapters/<chapter>/<demo>.html`
- Source URL: `https://github.com/createagle/html-guide/blob/main/chapters/<chapter>/<demo>.html`
- Demo pages hold only the demo (English copy, no explanations) and can be embedded in an iframe; the explanations live in the tutorial document.
- Apart from chapters 37–39, every demo is a zero-dependency HTML page you can open by double-clicking. All demos support dark mode and `prefers-reduced-motion`.
- Every Markdown file comes in English (`README.md`) and Chinese (`README.zh-CN.md`), linked to each other at the top.

### Adding a demo

1. Copy an existing demo page, then change its English `<title>`, controls and the markup in `.stage`.
2. Add a row to the table in the chapter's `README.md` and `README.zh-CN.md`.
3. Run `python3 tools/build_index.py` to regenerate `index.html`.

## Deployment

- `.github/workflows/sync-main.yml`: after a push to a `claude/**` branch, fast-forwards `main` and triggers a deployment.
- `.github/workflows/pages.yml`: deploys to GitHub Pages on a push to `main` (or when triggered by the workflow above).

First-time setup: in **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**, and make `main` the default branch.

Local preview:

```sh
python3 -m http.server 8000
# open http://localhost:8000/
```
